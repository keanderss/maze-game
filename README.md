# Maze game

The project should be runnable locally by running the following commands. If not you can check out the deployed version.

`flutter pub upgrade --major-versions`

`flutter run`

## Description

The application has a start screen, a level select screen, a game screen and a results screen.
The goal of the game is rolling a ball through a maze to a larger ball which marks the exit.

## URL

[Deployment](https://amazegame-a101c.web.app/)

## How to play

The game is played by controlling the ball in the maze using the joystick controller.
This can be played both in the browser and on a touch screen device.

## Breakpoints

The level selection screen has a breakpoint limiting the width of the level buttons on mobile layout.
The level selection screen also has a second grid layout for larger screens. This also features a
separate custom maxwidth at 1500 px.
